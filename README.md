# Reproduction of a page of El País

This repository contains a simple **HTML/CSS reproduction** of a page from *El País*, one of the major newspapers in Spain.  

The exercise was aimed at practicing:

- HTML structure (headings, articles, images, sections, columns)
- CSS styling (flexbox layout, responsive design, menus, typography)
- Semantic tags (`<article>`, `<section>`, `<nav>`, `<div>`)
- Responsive design using media queries


> **Note:** This is a **reproduction for educational purposes only**. The content is not original and mimics the structure of *El País*.
